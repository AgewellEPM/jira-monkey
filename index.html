Install — straight from GitHub

One line — installs the Monkey command onto your machine:

your terminal
$ curl -fsSL https://raw.githubusercontent.com/AgewellEPM/jira-monkey/main/install.sh | bash

Or with pipx / pip:

your terminal
$ pipx install git+https://github.com/AgewellEPM/jira-monkey.git
$ pip  install git+https://github.com/AgewellEPM/jira-monkey.git

Then run it:

your terminal
$ Monkey
🍌 Monkey · local coding, research, tickets and requests
$ Monkey --help   # every command
Requires Python 3.11+. The installer finds a suitable interpreter, prefers pipx, and falls back to pip --user.

What it does

🧠 Local by default

Reasoning runs on your own model (Ollama and friends). Nothing goes to a cloud model unless you opt in.

🧾 Signed work evidence

Every run produces a tamper-evident record — the plan, the steps, the outputs. Claimed work you can actually check.

🖥️ Real terminal jobs

Coding, research, tickets and requests, executed as bounded steps — not a wall of suggestions.

📦 Offline build runner

A captured, offline container for real multiprocess builds, with retained syscall evidence.

🍌 Terminal + web

A banana-themed console, plus an optional local web workspace sharing the same foreground session.

🔌 Connectors, gated

Connect the services you use through an explicit, auditable routing layer.
